# 定时提示词界面

依据 ui-ux-pro-max 的 Minimalism & Swiss Style（适用于专业工具和 dashboard）与表单提交反馈、标签可访问性指导实施。搜索返回的营销页 hero 模式不适用于这个插件，未采用。

- 主要任务：查看近期执行计划、创建或编辑提示词、定位运行异常。
- 当前项目：标题和新增按钮 → 项目切换 → 四项概览 → 按需编辑区 → 可折叠执行环境 → 计划列表和运行时间轴。
- 全部项目：汇总指标、筛选、项目任务卡片；保留跨项目操作。
- 主题：浅色白色卡片与近白背景；暗色纯黑背景、炭黑卡片。绿色用于主操作，成功、失败、暂停均有文字标签，避免只靠颜色表达。
- 字体沿用系统字体，无远程字体请求。正文 14px、辅助文字 12–13px，标题 24px。图标统一使用描边 SVG。
- 输入与按钮高度至少 44px，键盘焦点明显。时区、执行日期、时间都有可见标签；单次执行用日期选择器，按指定时区转换为 UTC 保存。
- 使用容器查询适配插件可用宽度：960px 以下列表与历史上下排列，600px 以下统计改两列、表单改一列。
- 无新增 UI 框架、模型调用或轮询。表单和执行设置保留 DOM，避免既有后台刷新清掉未保存内容。历史默认显示八条，其余按需展开。
- 例行验证使用 TypeScript 构建、服务和资源校验。浏览器交互、375px 和主题视觉验收由用户手动完成，不运行浏览器自动化。
